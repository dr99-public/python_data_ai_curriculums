# Data analytics curriculum
Teach students Python, data analytics, and AI (at a technical level), emphasizing foundational programming and data literacy. The initial goal is to teach enough Python so student can leverage it for data analytics workflows. 
## Python goals: 
 - Language basics: data types, definitions, conditional operators, and flows.
 - File i/o and API operations: file i/o, retrieval of content and data using APIs.
 - Debugging using VS Code Python Debugger extension
 - Basic data interaction: reading structured data (e.g. csv or xlsx) into data frameworks, database connectivity, database queries.
 - SQL: important departure from pure Python. Understand SQL basics and basic joins. 
 - Basic data interaction 2: manipulating and transforming data, persisting back to physical data (files or DB).
## Data Analytics goals
 - Fundamentas of structured data, re-cap relational data and joins, persisting data.
 - Data analysis basics: defining data and importance of semantics, measures, facts, dimensions, aggregation, trending.
 - Data analysis basics 2: counts and averages, distributions, variability.
 - Data analytis BI tools: basics of charting, graphing, visualizations.
## Target Audience
Students who capable of installing software on Windows / MacOS, navigate file systems, use basic productivity applications like Excel, Google Sheets, and text editors. Ideally, students will have basic familiarity of programming concepts from any language, but this isn't required.
## Tools
- Google Sheets or Excel.
- SQL-compliant database: SQLite or an administered RDBMS such as MySQL/MariaDB, PostgreSQL, etc.
- Visual Studio Code with Python, database, and SQL extensions.
- Github.
- Tableau Public or free Power BI accounts.
